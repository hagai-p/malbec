# Shortcuts

One-click links to the places used to run the Malbec sites.

## Windows (`windows/`)

Each `.url` file opens a page in your default browser.

1. Download `malbec-shortcuts-windows.zip` (or the `windows` folder) and unzip it.
2. Drag the files to the desktop, or right-click one and choose **Pin to Start**.

| Shortcut | Opens |
|---|---|
| Malbec Ventures - public site | www.malbec.ventures |
| Malbec Ventures - site on Vercel | malbec-web.vercel.app, the same site, reachable before the DNS switch (Vercel login needed) |
| Malbec Online - LP site | www.malbec.online (the old Base44 site until the LP site launches) |
| Vercel - malbec-web project | deployments, domains and settings |
| GitHub - malbec repo | the code |
| GoDaddy - DNS malbec.ventures / malbec.online | DNS records for each domain |
| Claude Code | claude.ai/code |
